# 💜 SITEFAN-BTS

Site de fã (Fandom) dedicado ao grupo sul-coreano **BTS**, desenvolvido com HTML, CSS e JavaScript puro, com estética lilás pastel e suporte completo ao **Modo Show (ARMY Bomb)**.

🔗 **Repositório:** [analiviaany-boop/SITEFAN-BTS](https://github.com/analiviaany-boop/SITEFAN-BTS)

---

## ✨ Funcionalidades

* **Home com Carrossel Dinâmico:** Troca automática e manual de fotos do grupo com o logo oficial do BTS em destaque.
* **Quem São:** Cards individuais e centralizados apresentando os 7 membros (*RM, Jin, Suga, J-Hope, Jimin, V e Jungkook*).
* **Mais Tocadas (Player Interativo):** Top 5 músicas com reprodução de áudio integrada, troca automática entre faixas e efeito de pulso lilás no card ativo.
* **Dicionário ARMY:** Cartões interativos com animação *Flip Card 3D*, escrita em Hangul e barra de pesquisa em tempo real.
* **Letreiro Fanchant:** Faixa animada contínua com o fanchant oficial dos membros.
* **Modo Escuro (ARMY Bomb):** Alternância entre o tema pastel claro e o tema roxo noturno ao clicar no logo do cabeçalho (com preferência salva no navegador).
* **Efeitos Interativos com Mouse:** Aura de luz lilás acompanhando o cursor e partículas temáticas (`💜`, `✨`, `💫`, `🪻`) ao clicar na tela.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estrutura semântica da página.
* **CSS3** — Flexbox, CSS Grid, animações 3D, efeito vidro fosco (*glassmorphism*) e temas claro/escuro.
* **JavaScript (ES6+)** — Controle de áudio, carrossel, filtro de busca, alternância de tema via `localStorage` e partículas interativas.

---

## 📁 Estrutura de Pastas

* `index.html` — Estrutura principal do site
* `style.css` — Estilos, responsividade e modo escuro
* `script.js` — Interatividade, player e efeitos
* `img/` — Logos, banners, fotos dos membros e capas dos álbuns
* `audios/` — Arquivos MP3 das músicas mais tocadas

---

## 🚀 Como Executar o Projeto

1. Clone este repositório com o comando `git clone https://github.com/analiviaany-boop/SITEFAN-BTS.git`.
2. Abra a pasta do projeto no **VS Code** (ou outro editor de sua preferência).
3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** para rodar localmente.
